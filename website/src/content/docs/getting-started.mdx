Claude Code Marketplace is a local web dashboard for the plugins in your Claude Code marketplaces. This page takes you from a first start to a first install.

## Requirements

- Node.js 18 or later.
- Claude Code on your `PATH`. The dashboard does every install, uninstall, enable, disable, and update through the `claude plugin` CLI. Check it:

  ```bash
  claude --version
  ```

## Start the dashboard

```bash
npx claude-code-marketplace --open
```

The server listens on port 3542 and prints this line:

```text
Claude Code Marketplace running at http://localhost:3542
```

`--open` opens that address in your default browser. If port 3542 is in use, the server prints `Port 3542 in use, trying random port...` and takes a free port. The banner shows the port it took.

To run from a clone of the repository instead:

```bash
npm install
npm start        # start the server
npm run dev      # start the server and open the browser
```

## What the dashboard reads

The dashboard reads the plugin registry in your Claude config folder, `~/.claude` by default:

- `plugins/known_marketplaces.json` lists the marketplaces you registered.
- `plugins/installed_plugins.json` records which plugins you installed, and in which scope.

If `known_marketplaces.json` does not exist, the tree is empty. It shows no marketplaces and no User Customizations or Project Customizations entries. Add one with the **Add** button in the top bar. See [Add and manage marketplaces](/claude-code-marketplace/guides/add-a-marketplace/). To use a different config folder, see [Configuration and CLI](/claude-code-marketplace/reference/configuration/).

## The first screen

<Shot themed="h1-hub-marketplace" alt="The dashboard with the marketplace tree on the left and User Customizations open in the detail panel on the right" />

The screen has three parts:

- The top bar has the search box, the scope filter, the project button, and the **Add**, **Refresh**, heatmap, color theme, light/dark, and help buttons, and a GitHub link.
- The tree on the left lists your marketplaces. Click a marketplace row to expand it and see its plugins.
- The detail panel on the right shows the item you select.

On the first load, the detail panel shows **User Customizations**. This entry and **Project Customizations** sit at the top of the tree. They list the skills, commands, agents, hooks, settings files, and `CLAUDE.md` files in your config folder and in the project's `.claude` folder. Each entry shows only when its folder has something to list. Project Customizations needs a `.claude` folder in the project. It also shows the project's root `CLAUDE.md` and `AGENTS.md`. You can view them, but you cannot install or remove them.

The scope filter starts at **Installed**, so the tree shows only plugins that you installed in some scope. Set it to **All** to see every plugin in every marketplace.

## Pick a project

The project and local scopes apply to one project folder. The top bar shows the current project on the folder button. At start, the current project is the folder where you started the dashboard, or the last project you picked in this browser. To change it, click the folder button or press <kbd>Shift+P</kbd>, and pick a recent project or add a path. See [Switch the project](/claude-code-marketplace/reference/configuration/#switch-the-project).

## Install as an app

The page is a progressive web app. In Chrome or Edge, use the install button in the address bar to open the dashboard in its own window. The app window needs the server to load data, and it opens the address you installed it from. Keep the server on the same port, for example with `--port 3542`.

## Install your first plugin

<Shot themed="marketplace" alt="A plugin selected in the tree, with the Scope Installation rows for user, project, and local in the detail panel" />

1. Set the scope filter to **All**.
2. Expand a marketplace and click a plugin. The detail panel shows its description, a **Scope Installation** section, and its components.
3. In the **user** row of **Scope Installation**, click **Install**.
4. A toast shows `Running install...`, then the CLI output, or `install successful` if the CLI prints nothing. The dashboard loads the data again, and the row changes to `Enabled · v<version>` with **Disable** and **Remove** buttons.

The user scope makes the plugin available in all your projects. To install for one project only, pick the project first and use the **project** or **local** row.
